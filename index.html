Sass-Build Live-Reload

Sass-Build

npm run scss:build erstellt das Stylesheet.

Die Farbe des ersten Buttons steht in src/scss/style.scss.

Live-Reload

Starte npm run scss:watch und npm run serve in zwei Terminals.

Beim Speichern siehst du die Änderung direkt im Browser.
